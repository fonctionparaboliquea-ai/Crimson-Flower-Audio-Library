# Crimson Flower Audio Library

Reusable human, weather, and Foley sound effects collected from the Sonniss **GameAudioGDC** free bundle. The original WAV files are kept here separately from the game repository for reuse in future projects.

## License and provenance

These files are from the Sonniss GameAudioGDC 2021–2023 bundle. The official license files are preserved in [`licenses/`](licenses/). Sonniss states that the GameAudioGDC sounds are royalty-free and commercially usable for media projects, including games, with no attribution required; redistribution as standalone sound effects is not permitted. Review the included license before using the files in a new project.

Source archive: <https://sonniss.com/gameaudiogdc/>  
Mirror used for individual-file retrieval: <https://gamesounds.xyz/?dir=Sonniss.com%20-%20GDC%202021-2023%20-%20Game%20Audio%20Bundle>

## Catalog

- `audio/human/`: human breathing and vocal reaction.
- `audio/weather/`: wind, rain, hail-on-glass, and ice cracking.
- `audio/foley/`: footsteps, doors, metal movement, belt movement, and impacts.

The game uses compressed derivatives of selected files; the original WAV sources remain in this repository.
